网站隐私政策Website Privacy Policy

更新日期 / Last updated: 2026-09-20

本政策适用于界外造物创意科技（青岛）有限公司（以下简称「我们」）的公司官网 www.jevaiworks.com。

This policy applies to www.jevaiworks.com, the company website operated by 界外造物创意科技（青岛）有限公司 (Jevai Works, “we”, “us”).

网站访问 / Visiting this website

本网站用于介绍公司及产品，不提供账户注册、在线支付或信息提交表单。网站本身不设置分析或广告 Cookie，不使用流量统计、广告追踪脚本或第三方嵌入内容，也不将访问信息保存在浏览器本地存储中。字体和图片随网站本身提供。

This informational website has no account registration, payments or submission forms. The site itself does not set analytics or advertising cookies, run analytics or advertising trackers, embed third-party content, or store visitor information in browser storage. Fonts use your device’s system fonts; images are served with the site.

托管服务 / Hosting

本网站计划通过 GitHub Pages 提供。网站上线后，托管服务可能处理提供网页及保障服务安全所需的技术信息，例如 IP 地址和请求日志。有关 GitHub 对此类信息的处理，请参阅 GitHub 隐私声明。

This website is prepared for hosting on GitHub Pages. Once hosted, the provider may process technical information such as IP addresses and request logs to deliver and secure its service. See the GitHub Privacy Statement for its data practices.

主动联系我们 / Contacting us

如果你通过公布的联系方式主动联系我们，我们会使用你提供的邮箱、姓名和消息内容回复咨询、处理合作或产品问题。请勿在初次联系中发送不必要的敏感个人信息。我们仅在处理相应事宜及履行适用义务所需的时间内保留这些联系信息。

If you contact us using a published contact channel, we use the name, email address and message you provide to respond and handle your enquiry. Please avoid sending unnecessary sensitive information. We retain correspondence only for as long as needed to address the matter and meet applicable obligations.

关于 Little Elsewhere / About the app

本政策仅说明公司官网的处理方式，不是 Little Elsewhere（别境）的应用隐私政策。应用发布前，将根据其实际功能与数据处理方式提供独立的隐私政策。

This policy covers the company website, not the Little Elsewhere app. A separate app privacy policy reflecting its actual functionality and data practices will be provided before release.

联系与更新 / Contact & updates

如需咨询本政策，或提出有关你向我们提供的信息的访问、更正、删除请求，请使用官网联系栏目公布的渠道。网站功能或数据处理方式改变时，我们会相应更新本政策及日期。

For questions about this policy or requests to access, correct or delete information you have shared with us, use the channel published in our contact section. We will update this policy and its date when the website or its data practices change.
