别境隐私政策

生效日期　2026年11月9日

本政策适用于别境 iOS 版。别境是一款专注应用，无需注册别境账号。你的详细专注记录和游戏进度主要保存在设备上。Plus 会员可以通过自己的 iCloud 备份和恢复数据。只有在你选择同意后，别境才会启用可选的使用统计和故障诊断。你可以随时在设置中关闭。

二、本机数据、导出与 iCloud 备份

别境在设备上保存专注记录、时长和目标，灵感笔记、待办和漂流瓶内容，收获、收藏、池塘和徽章，小鱼泡余额和地图解锁状态，以及你设置的名字和偏好。这些详细记录用于提供应用功能。我们没有用于接收这些完整记录的自有服务器。第 4 节说明在你同意后可能发送的有限使用事件。

在「设置 › 数据与隐私」中选择「导出备份」，可以把一份可读的记录副本保存到你选择的位置，或通过系统分享功能交给你选择的接收方。App Store 公开版支持导出，暂不支持从导出的文件导入恢复。

在 iOS 上，应用内 iCloud 备份对 Plus 会员默认开启。iCloud 可用时，别境会将最新的进度快照以带完整性签名的备份文件保存到你的 Apple 账户专属 CloudKit 私有数据库，记录备份时间、应用版本、设备型号和文件大小。我们无法从自己的系统读取你的私人备份。你可以在「设置 › 数据与隐私」关闭自动备份，也可以手动选择「立即备份」。Plus 到期后，你仍可从同一 iCloud 账户恢复已有的备份。恢复会替换这台设备上的现有进度。

这项功能按备份快照恢复进度，与设备系统备份分别管理。它不会在设备之间实时同步。中国大陆的 iCloud 服务由云上贵州运营。Apple 或云上贵州对 iCloud 数据的处理见各自政策。Apple 隐私政策 · 云上贵州 iCloud 隐私政策

如果你启用了 iCloud 设备备份或电脑备份等系统功能，系统也可能保存一份应用数据。卸载应用或选择「删除我的数据」会移除应用本机存储中的数据。已导出的文件、应用内 iCloud 备份和设备系统备份分别保留，由你在相应位置管理。开启或关闭应用内 iCloud 备份与可选统计及诊断的选择相互独立。

三、地区服务与同意选择

别境会先读取 App Store 商店所属的国家或地区。读取失败或超时时，依次参考上次成功读取后保存的地区、设备的地区设置，最后按系统语言所确定的应用语言选择。每次启动最多使用一组可选统计和诊断服务。中国大陆路线使用友盟+，其他地区路线使用 PostHog 和 Sentry。

路线依据商店或设备设置选择，与实际所在地可能不同。例如，在中国大陆使用境外 App Store 商店时，如果选择同意，统计和诊断数据可能发往德国。路线也不决定适用的个人信息保护法律。

当你在隐私提示中选择「同意并继续」，或在「设置 › 数据与隐私」中开启「帮助改进别境」，别境才会启用该地区的可选统计和诊断。两个用途由同一个开关控制。你也可以选择「仅使用基本功能」，专注计时等核心功能仍可使用。如果地区服务组发生变化，别境会在启用新的一组服务前重新征求同意。

四、可选的使用统计和故障诊断

经你同意后，别境使用以下信息了解功能使用情况、改进体验并排查问题。具体字段视服务商、事件和应用版本而异。

类别可能处理的信息

崩溃与错误错误类型、技术说明、程序堆栈、错误来源与严重程度、固定页面名称、应用与设备信息及使用场景。可能包括保存、渲染或 iCloud 备份失败等技术问题。应用上报的 JavaScript 错误会先过滤内容，以减少传送个人信息。原生崩溃记录由相关诊断 SDK 处理。U-APM 也可上报卡顿，Sentry 可上报疑似由系统看门狗终止应用的情况。

自定义事件还带有当前或专注所用场景、首页所选场景、内容版本、应用语言和发布渠道。使用事件不含专注目标、笔记、待办、漂流瓶纸条或其他输入文字的内容。地图解锁对话框记录的是在该对话框选择的操作。可选统计不会跟踪购买页面浏览或收集 Plus 购买及会员状态。

别境不请求定位权限、不读取 GPS 位置，也不收集广告标识符（IDFA）、通讯录、照片或麦克风内容。友盟+ 可能在服务器端根据网络信息（如 IP 地址）推断大致地理位置，例如国家、省份或城市。别境在你选择「复制」时写入剪贴板，不读取剪贴板。你使用专注完成提醒时，应用可能请求通知权限。

六、存储地点、IP 地址与保存期限

友盟+ 公开政策说明，其面向中国境内开发者的 SDK 服务在中国境内存储数据。岳鹰 SDK 公布的政策说明，在中国境内产生或收集的信息原则上存储在中国境内，部分信息可能在适用条件下传往境外。PostHog 和 Sentry 用于别境的项目配置为欧盟德国区域。根据地区路线及服务商的处理方式，可选数据可能跨境传输或访问。友盟+ 隐私政策 · 岳鹰 SDK 隐私政策

友盟+处理的统计分析数据： 友盟+仅在提供统计分析服务、维护相关服务记录以及保障服务安全与质量所需的期限内保留个人信息，法律要求或另有约定需要更长保留期限的除外。相应保存期限届满后，友盟+表示将删除相关个人信息或对其进行匿名化处理。具体请参阅《友盟+隐私政策》。

U-APM 与岳鹰 SDK 诊断数据。 根据友盟+ 和岳鹰 SDK 各自公开的政策，相关个人信息通常保留至实现诊断和服务保障等目的所需的期限届满。两项政策分别说明了可以延长保存的情形，以及期限届满后的删除或匿名化处理。友盟+ 隐私政策 · 岳鹰 SDK 隐私政策

PostHog 统计数据。 别境项目的统计数据保存 12 个月。项目配置为丢弃客户端 IP 地址，应用也关闭了 PostHog 根据 IP 推断地理位置的功能。PostHog 数据存储说明

Sentry 诊断数据。 别境项目的诊断数据保存 30 天。我们启用了防止 Sentry 存储 IP 地址的设置。应用的 JavaScript 上报路径还会移除用户 IP 地址、电子邮箱、用户名和请求数据等字段。服务商在接收网络请求时可能接触连接所用的 IP 地址，原生诊断记录由 SDK 单独处理。Sentry 隐私政策

本机数据保留到你删除、卸载应用或设备系统移除数据时。应用内 iCloud 备份在创建新备份时更新为最新快照，关闭备份或删除本机数据不会删除已有的 iCloud 副本。导出的文件、系统备份和 iCloud 数据的保留取决于你的管理操作以及相关服务。我们仅在处理反馈或隐私请求及履行适用法律义务所需的期限内保留相应往来记录。

七、撤回同意、删除和其他权利

你可以在「设置 › 数据与隐私」关闭「帮助改进别境」。应用会立即停止主动提交新的使用事件和错误报告，PostHog 会清除仍在本机队列中等待发送的事件，Sentry 关闭时可能发送已排队的报告。当前运行期间，已经启用的原生崩溃捕获可能持续至应用完全退出，包括友盟+ U-APM 的原生捕获。之后重新启动时，除非你再次同意，可选 SDK 不会启用。撤回不影响撤回前基于同意进行的处理，也不会自动清除已处理的数据或 SDK 留存的诊断记录。

你可以在应用内查阅进度、修改显示名字和设置，或使用「导出备份」取得本机数据副本。在「设置 › 数据与隐私」选择「删除我的数据」会清除本机数据。如果可选分享仍开启，应用会生成新的统计 ID。如果分享已关闭，应用会清除旧 ID，直到你重新同意才会生成新的 ID。单独关闭分享不会重置统计 ID。删除本机数据不会自动删除备份或服务商已经收到的记录。别境无需注册账号，因此无需注销。

你可以根据适用法律要求查阅、复制、更正、删除个人信息，限制处理、提出异议或向有管辖权的机构投诉。请通过 hello@jevaiworks.com 联系我们。我们会核实请求，并依法处理。若「数据与隐私」中显示统计 ID，你可以复制完整 ID 随请求提供，帮助我们定位相关记录。ID 缺失或已重置时，你仍可以提出请求。若现有信息无法定位记录，我们会说明限制及可行的下一步。

八、未成年人

别境面向一般用户，应用不询问年龄。在中国大陆，不满十四周岁的用户请在父母或其他监护人的指导下使用。处理不满十四周岁未成年人的个人信息，依法须取得其监护人同意并遵守适用的专门保护要求。在其他地区，例如美国，未满十三周岁或未达到当地法律规定的相应年龄的用户，也请在父母或其他监护人指导下使用。在取得适用法律要求的同意之前，请选择「仅使用基本功能」，关闭可选统计与诊断。如果监护人发现我们处理了未经所需授权的儿童个人信息，请通过 hello@jevaiworks.com 联系我们。我们会核实并依法处理。《中华人民共和国个人信息保护法》 · 美国联邦贸易委员会儿童在线隐私保护规则

九、信息安全与政策更新

我们使用加密连接与本政策列明的服务通信，并限制应用传送的字段。你的本机数据也受到设备系统和安全设置的保护。如发生依法需要采取措施或通知的信息安全事件，我们会依法采取补救措施，并履行相应的通知和报告义务。

应用功能或信息处理方式变更时，我们可能更新本政策并标明生效日期。需要额外通知或重新征求同意时，我们会在开始相关处理前完成相应程序。有关本政策的疑问、意见或投诉，可发送至 hello@jevaiworks.com。
