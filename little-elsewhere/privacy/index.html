三、保存在设备本地的信息

为提供专注计时、收集和个人记录等功能，别境在您的设备本地保存以下信息：

  • 专注记录：详细的专注历史、计划时长、专注目标及使用进度；
  • 个人内容：灵感笔记、待办事项和漂流瓶；
  • 收集进度：鱼类及其他渔获、图鉴、池塘和勋章；
  • 虚拟权益：小鱼泡（BUBS）余额及通过小鱼泡解锁的地图；
  • 个人设置：显示名称、偏好和其他应用设置。

我们不会将上述完整的本地记录上传到自有服务器。但是，在您同意可选统计分析后，部分与专注、渔获、地图及应用操作有关的有限使用事件可能发送至统计服务商，具体见第四条。您输入的笔记、待办事项和漂流瓶正文不会作为统计事件上传。

您可以自行导出一份可读取的数据副本，文件将保存在您选择的位置。设备操作系统自身的备份功能（如 iCloud 设备备份或电脑备份）也可能留存应用数据；别境目前尚未提供独立的应用内 iCloud 云同步或云备份服务。卸载应用或使用“删除我的数据”会移除相应的应用本地信息，但不一定清除系统备份，也不会自动删除此前已发送给第三方服务商的统计记录。删除本地数据时如何处理统计 ID，取决于当前是否开启了数据分享，详情见第九条。

请注意：“导出备份”用于取得和保存数据副本；当前公开发行版本不支持将导出的文件重新导入应用以恢复进度。设备系统备份的恢复能力则取决于相应设备与系统设置。详情请参阅《别境用户服务协议》。

设备权限及其他不收集的信息

别境的基本专注、垂钓与记录功能不需要访问您的相机、相册、通讯录、短信或精确位置。我们不为统计目的请求 GPS 精确定位权限，不使用广告标识符（IDFA），也不会为统计目的访问照片或麦克风。应用不读取您的剪贴板；只有在您主动点击“复制”时，才会向剪贴板写入内容。

如您选择接收专注完成提醒，应用可能请求系统通知权限。您可以在设备设置中拒绝或修改该权限，基本计时功能不受影响。购买或恢复 Plus 权益等功能可能需要网络连接。

我们不为广告追踪收集有效的 IDFA，也不要求精确 GPS 定位。不过，中国大陆友盟 U-APM 的实际诊断报告已出现 IP 地址及由 IP 推算的城市级位置；啄木鸟／岳鹰相关服务也可能处理网络类型、状态等信息。海外线路中，我们在 PostHog 客户端禁用 IP 地理定位推断，并在 Sentry 客户端关闭默认个人身份信息发送及过滤部分 IP 字段；第三方服务仍可能在网络连接或原生崩溃处理过程中接触 IP 等信息，其生产后台的实际保存和清理配置待进一步确认。

统计 ID、IDFV 和 UMID 不直接等同于您的姓名或邮箱，但根据适用法律，仍可能属于个人信息。对于仍可通过标识符关联的记录，我们不会仅因为其中没有姓名或邮箱，就将其称为“完全匿名”。

五、Plus 购买与会员权益信息

月度、年度订阅以及 Lifetime Plus 一次性购买，均通过 Apple App Store 处理。我们不会获取您的完整银行卡号或支付密码，也不会要求您在别境中输入 Apple 账户邮箱或密码。

为识别和恢复购买权益，应用通过 Apple StoreKit 读取商品 ID、购买和订阅状态、到期时间、宽限期、续订、试用及撤销状态，以及 App Store 的 Storefront 国家代码。本机 Plus 状态缓存保存套餐、到期时间、续订和试用状态及核验时间。应用不会要求或主动读取您的 Apple 账户邮箱或密码；当前实现不将交易 ID 写入 Plus 状态缓存，也不把交易 ID 作为统计事件主动发送。这些内容不代表我们能够访问您 Apple 账户的其他资料。

有关 Apple 如何处理支付和账户信息，请参阅 Apple 隐私政策。

七、处理目的与法律依据

我们使用保存在本地的信息为您提供专注、收集、记录及个性化设置等功能，并根据购买结果确认 Plus 权益。经您同意，我们利用第四条所述的有限信息了解应用使用情况、改善功能并排查故障。

您可以随时在“设置 > 数据与隐私”中关闭“帮助改进别境”，撤回对可选统计及诊断的同意。撤回同意将停止未来基于该同意开展的数据收集，但不会自动撤销此前已经依法开展的处理活动。

在适用欧盟《通用数据保护条例》（GDPR）或英国 GDPR 的情况下，我们会根据不同处理活动采用适用的法律依据，例如为提供核心功能与购买权益而履行协议、对可选统计与诊断取得同意，或者为必要的安全保障及履行法定义务而依据法律允许的其他依据处理。仅阅读或接受本政策，并不代表您已经同意可选统计分析。

八、数据保存地点、跨境处理及保存期限

您的详细个人进度与笔记通常保存在设备本地，除非您自行导出或使用设备备份。中国大陆地区使用友盟线路，其中啄木鸟／岳鹰 SDK 的具体存储位置仍待供应商确认；海外线路的 PostHog 已配置 EU Cloud，Sentry 配置为德国接收端点。生产后台的实际托管及访问方式仍需核实。

服务商可能因提供技术支持等需要在数据托管地以外访问相关信息。涉及个人信息跨境提供或访问时，我们将根据适用法律采取必要措施，包括依法履行告知、按要求取得单独同意或落实其他合法跨境传输机制。即使您位于中国大陆，只要应用依据地区路由选择海外统计服务，相关可选数据也可能传输至欧盟；应用商店地区并非判断是否适用中国个人信息出境规则的唯一标准。

我们仅在实现本政策所述目的以及履行法定义务所必要的期限内保留数据。以下具体期限须根据服务后台实际配置确认后，在正式发布前填写：

  • 友盟+ 统计及诊断信息：【待确认保存期限】；
  • PostHog 统计信息：【待确认保存期限】；
  • Sentry 错误及崩溃信息：【待确认保存期限】。

本地数据通常保留至您主动删除、卸载应用导致信息被移除，或设备及操作系统清除相应存储。设备备份中的副本可能在此之后仍然存在，具体取决于相应备份服务的管理规则。

十、未成年人个人信息保护

别境并非专门为儿童设计。未成年人应在父母或其他监护人的适当指导下使用本应用。如果您尚未达到所在地法律规定的可自行同意个人信息处理的年龄，请在监护人的指导下使用；在满足依法需要的同意及保护要求之前，请选择“仅使用基本功能”，不要启用可选统计或诊断。

应用商店的年龄分级属于内容分级，不代替适用的监护人同意与儿童个人信息保护要求。
